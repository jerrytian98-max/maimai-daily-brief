# maimai-daily-brief

把脉脉「同事圈」一天几百条讨论，压成**一屏能看完、每条都有结论**的中文日报。

> 不是又一个爬虫。核心是**怎么从噪声里挑出值得看的**：
> 默认设置下，一天 20 条新帖 / 500+ 条跟帖，最终只输出 3 条精选 + 5 条要闻。

## 它解决的问题

同事圈的信号噪声比很低：

- **最热的帖往往最没用** —— 点赞几百，但全是情绪共鸣，读完除了焦虑什么也没得到
- **最有用的帖常常沉底** —— 个位数赞，但写着「我已被沟通，12.30 走」这种能改变你行为的事实
- **大量提问没有答案** —— 「有人知道吗」「同问」「蹲一个」，评论区转一圈还是不知道

这个工具做三件事：**给可信度加权排序**、**只要找到结论的**、**让模型把半句话改写成完整结论**。

## 效果

```markdown
# 同事圈日报 · 11-15 22:00→11-16 22:00

新帖 23 ｜ 跟帖 572 ｜ 主线：赔偿年终(6) · 舆情风险(2)

## 今日精选

**1. WXG年终奖现金股票比例有5:5、4:6、3:7、3:1多种说法** [原帖](…)
**2. 今年年底五星90%安全，部门合并裁撤会有影响** [原帖](…)
　背景：年中或年底拿到五星90%是安全的……
**3. IEG公线某部打五折，已沟通完毕** [原帖](…)

**要闻**
- [行动] 离职流程最后日期可写在1月15之后，极速交接1天也可按该日期离职　[原帖](…)
- [动向] 年底广进重点对象是各工作室中台、IEG GLOBAL、IEG 技术公线　[原帖](…)
```

标题就是结论，一屏读完不用点进去。

## 快速开始

```bash
pip install requests

# 1. 从本机 Chrome 导出登录态（需已在 Chrome 登录脉脉）
python scripts/chrome_cookies.py --list
python scripts/chrome_cookies.py "Default"

# 2. 复制配置并填写
cp config.example.json config.json
#   circle.webcid  ← 同事圈页面 URL 里 webcid= 后面那串
#   llm.*          ← 任何 OpenAI 兼容端点（可关闭）
#   push.webhook   ← 企业微信群机器人地址（可关闭）

# 3. 跑
python scripts/run_daily.py --push
```

## 设计取舍

| 决定 | 原因 |
|---|---|
| 可信度做**乘数**而不是加数 | 一条疯传但没来源的帖不该排第一 |
| 没结论就淘汰，宁缺毋滥 | 宁可当天只出 1 条，也不拿问句凑够 3 条 |
| 规则筛 + 模型写 | 规则能判断「有答案」，但剪出来是半句话 |
| 模型有否决权 | 它判定「材料里没答案」就填 null，比规则更准 |
| 不显示排序依据 | 「44 赞 / 已略过 41 条」是给作者看的，读者只要结论 |
| 链接跟正文同行 | 单独占行会把 1 屏撑成 2 屏 |

## 已知边界

- 需要脉脉登录态（cookie），**过期后需重新导出**
- 只读自己能看的内容，默认 0.3 秒请求间隔，不并发
- 企业微信 markdown 上限 4096 字节，输出压到 3900
- 模型可选：不配也能跑（退回纯规则版），配了质量更好
